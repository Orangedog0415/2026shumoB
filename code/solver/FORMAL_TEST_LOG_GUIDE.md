# 正式测试结果与日志使用说明

1. 每次正式测试前在 `outputs\official\` 下新建独立输出目录，禁止覆盖前一局；官方模式未提供 `--output-dir` 时程序会拒绝启动。
2. 记录模拟器显示的测试案例编码和程序现实运行时间。
3. 将 `summary.json` 中的清除数和虚拟时间与模拟器界面核对。正式测试不披露源总数，不自行猜测清除比例。
4. 在 `formal_results_template.csv` 填写三局数据；零清除时平均定位清除时间写 `N/A`。
5. 从模拟器导出对应加密行为日志，保留原文件名，并在模板最后一列建立一一对应关系。
6. `actions.jsonl` 是本程序的复查日志，不替代模拟器生成的官方加密日志，也不得包含密码。
7. 结束类型不是 `COMPLETED` 时必须按异常退出记录，不得标注为正常全清。
