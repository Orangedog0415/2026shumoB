# 实现说明与差异记录

## 材料路径

当前实现以仓库内 `docs/handover/交接材料.md` 和 `docs/plan/2026国赛B题_最终可执行思路.md` 为规格来源；题目、附件、研究脚本和历史材料均未修改。

## 相对参考脚本的工程化变化

- 问题三、四的默认控制器现为方案四（策略 B）：Q3 使用半径 974 m 的无中心八点环，Q4 使用边长 950 m、偏移 `(475, 411.4)`、旋转 30° 的 27 点三角格网；覆盖路径经最近邻和 2-opt 排序，每个覆盖点扫完全部未知频道，并对几何条件合适的活动频道补测。可能区域半径不超过 130 m 且绕行不超过 530 m 时顺路清除，覆盖完成后使用确定性 ALNS 排序集中清除。原方案一保留为 `--strategy a` 回退入口。
- 方案四的局部控制器使用方位楔与 1500 m 接收上界更新可能区域；区域半径不超过 19.5 m 时直接清除，可被至多六个 28 m 方格覆盖时尝试有限清除，否则以 540 m 距离上限和 40° 长轴夹角最多补测两次，再进入有限网格兜底。策略只依据接口观测和自身状态，不使用本地仿真真值。
- 原参考脚本把包含真实源数据的 `World` 对象直接传给控制器。新实现把真值保存在 `_SimulatorCore` 中，只把 `ObservationClient` 外观交给策略；策略模块不导入模拟器，也不读取源数量、位置、半径、类型、朝向或清除真值。
- 参考脚本以目标圆外包络作为问题一计算起点。正式实现同时提供纯半平面交分类和独立的在线外包络，避免用目标圆盘悄悄截断问题一结果。
- 半平面求交增加空集、无界、点、线段、数值不确定分类；近平行行列式使用 50 位十进制复核。直径同时运行枚举和旋转卡壳，不一致时不输出伪造的确定值。
- 清除失败圆盘和凸外包络分开保存。快速层只承担提速，有限 75×3 网格及未剪枝补查真实进入控制代码。
- 官方客户端在发送前原子写入未决请求，只有 HTTP 状态和 `accepted=true` 均合格后提交位置、测向频道和虚拟时间。`accepted=false` 是已确认未执行，会清除未决标志并异常结束；响应未知则保留未决文件，禁止发出不同动作或 `/exit`。
- 异常退出回归测试曾发现 Python 会在 `except` 结束后清除异常绑定，导致摘要阶段引用失效；现将异常文本立即复制到独立字段，并以预算不足和通信异常测试锁定四类终止结果。

## 数值与证据边界

问题二严格使用 50 米测点网格、100 米边界采样和误差 `{-1.005°,0,1.005°}`。输出文本明确说明这不是连续全局最优或严格连续最坏误差证明。圆盘始终使用外切 64 边形，失败清除只形成单独的排除证据。

本地随机结果只验证实现闭环，不是官方演练或正式成绩。官方账号登录、服务器时间校验、真实服务延迟、正式次数、加密日志导出和上传均未在本地自动执行。
