## 1 自动推荐结果

### 问题1

- 首选：半平面交 + 旋转卡壳 + 最小覆盖圆。
- 备选：边界交点枚举 + 凸包 + 两两距离。
- Baseline：角扇形密集采样。
- 推荐理由：数据是确定性有界几何约束，不是带分布的回归样本；首选模型可以精确处理直径和覆盖圆问题。

### 问题2

- 首选：保证接收约束下的鲁棒极大极小选点。
- 备选：基于演练分布的期望信息增益选点。
- Baseline：第一示向线两侧固定横向偏移。
- 推荐理由：第一次测量没有距离信息，使用最坏定位直径可避免虚构距离先验；双侧固定点保留为解释和程序降级方案。

### 问题3

- 首选：7点覆盖证书 + 频道状态机 + 集合型主动定位 + 最小覆盖圆清除 + 覆盖保底的自适应路线。
- 备选：候选覆盖点集合上的整数规划压缩 + TSP路径 + 在线重规划。
- Baseline：密集格网逐点扫描20频道。
- 推荐理由：问题既要求不漏检，又要缩短时间。固定覆盖证书提供完成性，自适应层减少不必要扫描和绕行；单独使用POMDP难以给出最坏保证。

### 问题4

- 首选：三角格局部半平面覆盖证书 + 位置方向联合可行域 + 20米扇形覆盖清除兜底。
- 备选：多分辨率三角格 + 6/8点局部角向探测 + 粒子信息增益。
- Baseline：直接复用问题3的圆盘覆盖，仅作失败对照。
- 推荐理由：定向源把普通距离覆盖问题提升为方向覆盖问题；局部凸包证书能直接对应180度发射半平面，扇形清除利用了清除与发射方向无关这一题目特性。

## 3 创新点与消融设计

### 创新点1 直径与可清除性的统一

- 传统做法：交会后给出一个点估计。
- 本题改动：保留完整有界误差可行域，并以最小覆盖圆半径不超过20米作为清除停止条件。
- 预期收益：把定位误差直接转换成确定性的清除成功保证。
- 消融：比较“交点直接清除”和“覆盖圆判据清除”的失败次数与额外测量次数。

### 创新点2 覆盖证书与自适应加速分层

- 传统做法：固定网格或纯贪心搜索二选一。
- 本题改动：固定覆盖证书只负责最坏完成性，自适应动作只负责提前发现、复用测点和减少绕行。
- 预期收益：避免纯贪心漏源，同时减少固定全扫描冗余。
- 消融：固定全扫描、无证书贪心、证书引导自适应三组公平比较。

### 创新点3 定向源的局部凸包覆盖

- 传统做法：仍用距离圆盘覆盖。
- 本题改动：以 \(G\in\operatorname{conv}(Q\cap B(G,1000))\) 表达任意180度发射方向的发现条件，并用三角格给出构造。
- 预期收益：把方向未知的漏检风险转化成可计算验证的几何证书。
- 消融：相同测点数下比较圆盘覆盖点集和局部凸包覆盖点集的最坏方向发现率。

### 创新点4 单次正向测量后的方向无关清除兜底

- 传统做法：必须取得两条正向测线才能继续。
- 本题改动：若定向遮挡使后续正向测量困难，用20米圆覆盖一次测向形成的窄扇形；清除不受发射方向限制。
- 预期收益：保留确定性终止路径。
- 代价：失败清除次数可能较多，只在信息选点失效时启用。

## 4 防模型堆砌检查

- 去掉最小覆盖圆会失去20米清除保证，不能去掉。
- 去掉问题3覆盖证书会失去未知总数下的完成判据，不能去掉。
- 去掉问题4局部凸包条件会重新引入定向漏检，不能去掉。
- POMDP、遗传算法、蚁群等名称不会带来唯一必要输出，当前不作为主模型。
- TSP/整数规划只用于压缩覆盖路线，不冒充定位模型或创新本身。
