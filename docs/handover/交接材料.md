三、必须守住的正确性边界

- /clear不切换测向机频道，也不产生切换费用。
- 移动按相邻已接受动作的位置累计，不能只按相邻测量点累计。
- 接收信号不等于必有方位；near必须独立处理。
- 混合场景不能把所有源当作定向源施加半平面约束。
- 覆盖证据必须按频道记录，走过网点不等于检测过全部频道。
- 同一点误差固定，不能靠原地反复测量假设独立降噪。
- 数值近似必须保守，不得把内接多边形当安全外包络。
- ACTIVE频道的数值空集或后续无信号不能直接变为空闲。
- 启发式提速不承担全清证明；有限兜底必须真实进入代码。
- 失败清除的排除信息与凸外包络分别维护，不错误扩大或裁掉真实源。

策略只能通过观测接口获取信息。模拟器可以持有真实源数据，但策略不得访问源坐标、真实数量、半径、类型、朝向或隐藏清除状态。
建议用不同对象或进程隔离；不要让策略接收一个可随意读取内部真值的World对象。

第2步：瓶颈诊断（证据：docs\review\最终方案审查.md）
- 调度“发现即走”：在覆盖点扫到一个有信号的频道就中断扫描去清它，清完再回来，每个源一次往返；其他覆盖点对同一源的方位没有被利用。

第3步：队伍提出的改进思路
- 不再发现即走：每个覆盖点先扫完所有未确认频道，再决定下一步。
- 设参数x：位置已能确认的源，若顺路（绕行不超过x）就先去清，清完回到覆盖主线；否则暂缓。
- 所有频道覆盖完成后，把剩余的源按最短路依次清除。
- 问题三的覆盖路线不必是“中心+六边形”，可增加多边形边数、缩小环半径，缩短覆盖路线。

第4步：仿真验证与修正 → 方案三（证据：code\experiments\方案三_参数扫描.py、results\方案三_参数扫描输出.txt；问题三、四各30局，N=10/13/16各10局）

9.2 策略B规格
1. 覆盖网
   - 问题三：8个点位于以原点为心、半径974 m的正八边形顶点，不设中心点。任意目标点到最近网点的最大距离为 max(974, √(1800²+974²−2·1800·974·cos22.5°)) ≈ 974.3 m，余量约25.7 m。
   - 问题四（方案七）：25个点的**非规则三角网**，巡回17 547 m，坐标见 方案四_实验台.py 的 NET4_V7。
     证书：对点集做 Delaunay 三角剖分，要求 (1) 凸包包住半径1800 m圆盘；(2) 每个与圆盘相交的三角形三边均 ≤1000 m。
     于是任一源落在某三角形内，到三顶点距离 ≤ 最长边 ≤1000 m（三角形直径即最长边），且被三顶点围住 ⇒ 任何定向方向下至少一个顶点能收到。
     这与最终文档 §5.2 的三角格证明同构，只是顶点不必在规则格上。实测最长边995.8 m，另用“位置×朝向”稠密检查复验：漏测0；用 GT06 式(31) 的全域最大方位间隔独立复核为 179.86°<180°。
     实现时必须在启动前用同样的两步（解析边长检查 + 稠密复验）验证所用坐标表，验证不通过就依次退回方案六的 NET4_V6（27点，17.8 km）与方案四的 h=950 规则格网（25.1 km），两者也都已验证。
     生成方法见 方案五_5.2_非规则三角网优化.py 与 方案六_6.4_覆盖网再压缩.py（同心环枚举给起点 + 模拟退火，需 numpy/scipy），退火有随机性，不要求复现同一张网。
   - 覆盖点访问顺序：问题三从原点出发按最近邻 + 2-opt 固定；问题四见第4′条（联合重规划，不用固定巡回）。
2. 每到一个覆盖点，测完该点所有未确认频道（当前测向机频道优先，其余按编号），不因发现信号中途离开。返回near时立即原地清除。
3. 顺带补测：对已发现未清除的源，若本点到其可能区域所有顶点都≤1500 m，且与该源已有各条方位的夹角都≥12°，在本点顺带测一次该频道，用新方位裁剪区域。
4. **问题三**：离开覆盖点前，对区域半径≤r_ok 的已发现源，计算绕行距离 = d(当前位置, 区域中心) + d(区域中心, 下一覆盖点) − d(当前位置, 下一覆盖点)，取最小者；若≤x，先去清它，清完回到主线再重新判断。
4′. **问题四（方案六/方案七，调度相同）**：不用固定巡回与 x 阈值，改为每一步联合重规划——
   把“还有未确认频道的覆盖点”和“区域半径≤r_ok 的已发现源”放在一起，从当前位置排一条最近邻 + 2-opt 的开放路线，
   执行排在最前的那个节点，然后重排。其中每个源用**服务簇**表示：区域半径≤19.5 m 时只有区域中心一个服务点，
   否则取覆盖该区域的 ≤6 个 20 m 清除圆中心，节点坐标取离当前位置最近的那个服务点。
4″. **计数提前停（两问都适用，实际只在 N=16 触发）**：当“已清除 + 已发现”达到 16 时，题目保证总数 ≤16 且每频道至多一个源，
   故其余频道必为空，立即停止覆盖转入集中清除。**这是与覆盖证书并列的第二条判空依据，必须写进保证链与论文。**
5. 局部清除（参考 方案二_调度改进原型.py 的 local_v2）
   - 区域半径≤19.5 m：到区域中心清除（保证成功；失败即转ERROR）。
   - 区域能被≤6个20 m清除圆覆盖（在区域主轴坐标系中用28 m方格切分，保留与区域相交的格子）：按最近顺序逐格清除。
   - 否则补测：候选点在区域中心周围，距离取 max(区域半径+15, min(540, 当前位置到中心的距离)) m，方向与区域长轴夹角≥40°；问题四优先选在已有信号点相对源的角度范围内（覆盖区是凸集，更可能收到信号）；取离当前位置最近者；最多补测2次。
   - 仍未清除：进入最终文档 §6.2 的75×3有限兜底，原样执行。
6. 覆盖全部完成后：**问题三**用 ALNS（随机/最差移除 + 最小插入修复 + 2-opt，200次迭代，起点为当前位置）排定剩余源的清除顺序，
   再逐个执行第5步；ALNS 不可用时退回最近邻（约慢2%）。**问题四**由第4′条的联合重规划自然接管，不需要单独的收尾排序。
7. 覆盖证书、频道状态、退出条件（清满16个，或其余频道在全部覆盖点均无信号）和异常分支与最终文档相同。
