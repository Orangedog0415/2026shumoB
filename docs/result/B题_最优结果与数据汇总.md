## 1 问题一：定位区域、直径与直径圆覆盖

### 1.1 建模

第 i 次测向返回示向度 θ̂ᵢ，测点 Sᵢ。取保守角度界 δ=1.005°（包容两位小数舍入），单次观测给出一个**误差楔形**（两个半平面的交）：

$$W_i=\{X:(X-S_i)\cdot n(\hat\theta_i-\delta)\ge 0,\ (X-S_i)\cdot n(\hat\theta_i+\delta)\le 0\},\quad n(\theta)=(-\sin\theta,\cos\theta)$$

定位区域即 **纯楔形交集** $P_w=\bigcap_i W_i$（问题一的输出**不**用目标圆盘截断）。有界时其直径

$$D_P=\max_{i,j}\lVert V_i-V_j\rVert$$

设直径端点 A、C，中点 M=(A+C)/2，则**直径圆覆盖定位区域 ⟺**

$$\max_i\lVert V_i-M\rVert\le D_P/2\quad\Longleftrightarrow\quad \max_i (V_i-A)\cdot(V_i-C)\le 0$$

（Thales 等价形式：所有顶点看直径端点的张角 ≥ 90°。）平面集合满足 $D_P/2\le R_{\rm MEC}\le D_P/\sqrt3$，最坏情形为正三角形（比值 √3/2≈0.866，即 1.732·(D/2)）。

### 1.2 算法

1. **求交**：全部约束写成 $a_j\cdot X\le b_j$。① 枚举原点、原点到各边界直线的垂足、所有非平行边界线交点找可行点，无可行点 → `EMPTY`；② 枚举各边界单位切向判衰退锥 → `UNBOUNDED`；③ 收集满足全部约束的边界交点、去重、凸包、逆时针排序；点/线段作退化集单独返回。
2. **增量裁剪**：已有有界多边形时用 Sutherland–Hodgman，交点 $X=A+\frac{f(A)}{f(A)-f(B)}(B-A)$。
3. **直径**：旋转卡壳 O(h) 为主实现，顶点枚举 O(h²) 为校核实现，二者互校。
4. **数值分支**：长度容差 1e−7 m、方向容差 1e−12；行列式过小则以 50 位十进制重算，仍不稳定返回 `NUMERIC_UNCERTAIN`（**不得把不确定当空集**）。
5. **在线外包络**：圆盘用**外切** 64 边形 $O_{64}(c,r)$ 表示，径向外扩 $r(\sec(\pi/64)-1)$ ——1800 m 圆约 **2.171 m**，1500 m 圆约 **1.809 m**；在线区域 $P\leftarrow P\cap W(S,\hat\theta)\cap O_{64}(S,1500)$，初值 $O_{64}(0,1800)$。只有 $P\subseteq B(C,20)$ 才能保证在 C 清除。

### 1.5 结论（问题一的最优结果）

1. 定位区域是各次观测误差楔形的交，为凸多边形（可能退化为空集、点、线段或无界）。
2. 其直径由旋转卡壳给出，并与顶点枚举互校，300 组算例上最大差 0.0 m。
3. **以直径为直径的圆不一定覆盖定位区域。** 判据为 $\max_i\lVert V_i-M\rVert\le D_P/2$；在真实测向构型生成的 3000 组算例中有 **17.87%** 不覆盖，最坏比值 1.6528，接近理论上界 √3。若要保证覆盖，应取最小包围圆，其半径满足 $D_P/2\le R_{\rm MEC}\le D_P/\sqrt3$。

## 2 问题二：第二检测点的选取

### 2.1 建模

首次观测返回示向度后，**精确可行状态集**为

$$\Omega_1=\{(G,r):G\in\mathcal D\cap W_1,\ 1000\le r\le 1500,\ 5<\lVert G-S_1\rVert\le r\}$$

（首次观测不只给角度，还排除了接收半径之外与 near 范围之内的状态。）

保证第二点**一定能收到信号**的精确条件 $C_{\rm exact}=\{S:\sup_{(G,r)\in\Omega_1}(\lVert S-G\rVert-r)\le0\}$ 不便实现，改用更保守、可认证的**充分条件**

$$C_{\rm safe}=\{S:\max_{V\in\operatorname{vert}(P)}\lVert S-V\rVert\le 1000\}$$

（P 包含真实源位置，距离是凸函数，在多边形上的最大值必在顶点取到。实现时再留 1 m 余量，用 ≤999 m。）

选点目标为**有限样本的最坏后验直径**加移动时间惩罚：

$$F(S)=\hat J(S)+0.05\cdot\frac{\lVert S-S_1\rVert}{5},\qquad \hat J(S)=\max_{G\in\text{样本},\,e\in\{-\delta,0,\delta\}}\operatorname{diam}\big(P\cap W(S,\operatorname{atan2}(G-S)+e)\big)$$

0.05 的单位为 m/s，使评分量纲一致；这是固定设计权重，不代表物理定律。**有限样本结果不是连续极小化极大的证明。**

### 2.2 算法

- **基线（最终文档采用）**：50 m 网格扫描。候选 $S=S_1+a\,u+b\,w$，a=0,50,…,1500，b=−1000,−950,…,1000（31×41=1271 个），保留满足 ≤999 m 认证的点。
- **最优（采用）**：**差分进化 DE**（连续全局求解），5 次独立运行（1 次以网格解作初始个体，4 次纯随机初始），在同一目标 F 与同一采样口径下求连续最优。
- 合格中心集 $A=\{S:F(S)\le 1.2F_{\min}\}$；每个中心取 $\epsilon_S=\min\{10,(1000-\max_V\lVert S-V\rVert)/2\}$ m，输出候选区域 $\mathcal C=\bigcup_{S\in A}B(S,\epsilon_S)$（三角不等式保证区域内每点都满足接收充分条件）。
- 并列排序：按 $(F,\lVert S-S_1\rVert,a,b)$ 字典序。候选为空时补入 $S_1+750u$ 检查；仍不能认证则报几何输入异常，**不把「没有候选」当目标不存在**。

### 3.2 建模与算法

**覆盖证书（保证发现全部全向源）**：8 个测点位于以原点为心、半径 974 m 的正八边形顶点，不设中心点。任意目标点到最近网点的最大距离

$$\rho=\max\Big(974,\ \sqrt{1800^2+974^2-2\cdot1800\cdot974\cos 22.5^\circ}\Big)=974.2612\ \text{m}<1000\ \text{m}$$

余量 **25.74 m**。巡回长度 6192.3 m（最近邻 + 2-opt，自原点出发）。

> 对照：基线方案一用「中心 + 6 点半径 1200 m 环」共 7 点，覆盖半径 968.90 m、余量 31.10 m，巡回 7200 m。集合覆盖 LP 松弛下界为 5.88（整数最优 ≥6，实际最少 7 点），但**最少点数 ≠ 最快**：按时间目标 8 点正八边形最好（8 边形 334–336 s/源，10 边形 335，12 边形 342）。

**调度（方案四）**：

1. 每到一个覆盖点，**测完该点所有未确认频道**（当前测向机频道优先，其余按编号），不因发现信号中途离开（基线是「发现即走」，每源一次往返）。
2. **顺带补测**：对已发现未清除的源，若本点到其可能区域所有顶点 ≤1500 m，且与该源已有各条方位的夹角均 ≥12°，顺带测一次并用新方位裁剪区域。（关掉这一条，问题三从 346 升到 550 s/源。）
3. **顺路清除**：离开覆盖点前，对区域半径 ≤ r_ok 的已发现源，计算**绕行距离** = d(当前位置, 区域中心) + d(区域中心, 下一覆盖点) − d(当前位置, 下一覆盖点)；取最小者，若 ≤ x 则先去清，清完回主线再判断。
4. **覆盖完成后**用 **ALNS**（随机/最差移除 + 最小插入修复 + 2-opt，200 次迭代）排定剩余源的清除顺序（不可用时退回最近邻，约慢 2%）。
5. **局部清除**：区域半径 ≤19.5 m → 到区域中心清除（保证成功）；区域能被 ≤6 个 20 m 清除圆覆盖（区域主轴坐标系下用 28 m 方格切分）→ 按最近顺序逐格清除；否则补测（候选点距区域中心 max(区域半径+15, min(540, 当前距中心距离))，与区域长轴夹角 ≥40°，最多 2 次）。
6. **有限兜底**：仍未清除则进入 **75×3=225 格**有限清除网格，原样执行（最坏 675 s 上界）。
7. **退出**：清满 16 个，或其余频道在全部覆盖点均无信号（覆盖证据**按频道**累计）。

### 4.2 建模与算法

**覆盖证书（保证发现任意朝向的定向源）**：25 点**可认证非规则三角网** NET4_V7。

- 判据：对点集做 Delaunay 三角剖分，要求 ① 凸包包住半径 1800 m 圆盘；② 每个与圆盘相交的三角形三边均 ≤1000 m。
- 于是任一源落在某三角形内，到三顶点距离 ≤ 最长边 ≤1000 m，且**被三顶点围住** ⇒ 任何发射朝向下至少一个顶点落在前向半平面内且在接收半径内，必能收到。
- 实测：与圆盘相交的三角形**最长边 995.8 m**；用 GT06 式(31) 的全域**最大方位间隔 179.86° < 180°** 独立复核（两套判据数学等价）；「位置×朝向」稠密复验（360×62×72）**漏测 0**。
- 巡回 **17 547 m**（对照：方案四 h=950 规则格网 27 点 25 111 m；方案三 h=990 格网 27 点 26 679 m；方案六 27 点 17 830 m）。
- **启动前自检**：解析边长检查 + 凸包含圆；失败依次退回 NET4_V6（27 点，17 830 m）与 h=950 规则格网（27 点，25 111 m）。

**调度（方案六/方案七相同）**：

1. **每步联合重规划**：把「还有未确认频道的覆盖点」和「区域半径 ≤ r_ok 的已发现源」放在一起，从当前位置排一条最近邻 + 2-opt 的开放路线，**执行排在最前的那个节点，然后重排**（不用固定巡回与 x 阈值）。
2. **服务簇**：每个待清源用 ≤6 个清除圆中心表示（区域半径 ≤19.5 m 时只有区域中心一个服务点），节点坐标取离当前位置最近的那个服务点。
3. **计数提前停**：当「已清除 + 已发现」达到 **16** 时，题目保证总数 ≤16 且每频道至多一个源，故其余频道必为空，立即停止覆盖转入集中清除。**这是与覆盖证书并列的第二条判空依据。**
4. 每到一点扫完所有未确认频道、顺带补测、局部清除、75×3 有限兜底、频道状态机与异常分支均与问题三共用。
5. 定向/全向**不做类型判别**：对两类源都只用 `direction` 的楔形与 1500 m 上界；`near` 立即原地清除；对 ACTIVE 频道的 `no_signal` 只记历史，**不施加未经证明的「背向」或距离剪枝**（避免把全向源错误排除）。

### 6.3 口径与注意事项

1. **全部为本地仿真的虚拟时间**，按模拟器规则逐动作累计：移动 ‖Δp‖/5 s，检测 5 s（换频道 +1 s），清除成功 5 s / 未发现 3 s；`/clear` 不切换测向机频道也不计切换费用；移动按**相邻已接受动作**的位置累计。校验例：原点测频道 1 → (300,400) 清频道 3 成功 → 回原点测频道 1，共 **215 s、0 次切换**。
2. **平台差异**：Linux 复跑方案一时有 3 局因三角函数末位差异相差 2.6–6.5 s，其余一致；回归比较按容差进行。本文数据在 Linux / Python 3 下产生。
3. **压力测试的案例集依赖 `hash()`**：`方案七_运行.py` 与 `_绘图数据采集.py` 用 `abs(hash(误差模型名))` 作随机种子，而 Python 字符串 hash 每进程随机化，因此**两次运行的 180 局案例集不同**（本文 §4.6 表为 `绘图数据.json` 那一批：均值 656 s、最大 950 s；`方案七_运行输出.txt` 那一批为均值 662 s、最大 966 s）。两批的结论一致——未全清 0 局。若需逐局可复现，应把该种子改为固定常数。
4. 问题一、二的数值结果是**可复算的设计例**，不是官方案例、连续最优坐标或精度保证；问题二的 Ĵ 基于有限样本，**不构成连续最坏情况的证明**。
5. 方案一（策略 A）保留为基线与退路：若演练中策略 B 出现未清除、异常或明显慢于策略 A，则依次退回方案六 → 方案四 → 方案一。策略与参数只能在正式测试开始前决定。
