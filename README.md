## 运行（Windows PowerShell，仓库根目录，只需 Python 3 标准库）

```powershell
# 交接验证脚本（约 5 s）。注意：它会覆盖同目录的 最终方案验证结果.json，运行后可用 git restore 还原
python code\baseline\最终方案验证.py

# 策略 A 压力测试 960 局（约 1 分钟），结果写到 code\experiments\results\
python code\experiments\压力测试.py

# 策略 B 原型：与策略 A 对比（数分钟）
python code\experiments\调度改进原型.py

# 顺路清除参数 x / r_ok、顺带补测、覆盖网对比（约 1–2 分钟）
python code\experiments\参数扫描_顺路清除x.py
```

所有时间均为按模拟器规则计算的虚拟时间，来自本地仿真，不是官方演练或正式测试成绩。
