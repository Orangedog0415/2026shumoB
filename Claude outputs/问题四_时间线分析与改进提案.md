## 1. 题目与时间模型（自足摘要）

- 目标区域：以原点为心、半径 1800 m 的圆盘 D。机器狗从 (0,0) 出发，测向机初始频道 1，可以走到圆外。
- 干扰源：总数 N ∈ [10,16]，个数未知；频道 1–20，**每个频道至多一个源**；每源有效接收半径 r_c ∈ [1000,1500] m（未知、逐源不同）。
- 问题四中源分全向与定向两类：定向源只在"定向方向两侧各 90°（含边界）"的半平面内辐射，方向未知。
- 测向：在一点对一个频道检测，返回 `direction`（示向度，误差 ±1°，读数保留两位小数）/ `near`（距离 ≤5 m 且在覆盖角内）/ `no_signal`。
  **同一地点误差固定**，重复测量没有新信息。
- 时间：移动 5 m/s；每次检测 5 s；切换频道 1 s（只有 `/measure` 会切）；清除成功 5 s、未发现 3 s；
  清除半径 20 m，与定向方向无关。总时间 = 移动 + 检测 + 切换 + 清除。
- 评价：先要求**全部清除**，再比"平均定位清除时间 = 总虚拟时间 ÷ 清除个数"。
- 现实约束：单局程序运行 ≤20 min、测试窗口 25 min（本文不涉及，动作数当前最多约 700 次，不是瓶颈）。

## 2. 当前方案（方案四）规格

保证层（**不可改动**，改了就失去"确保全部清除"）：

1. **方向覆盖证书**：边长 h ≤ 1000 m 的正三角形格网，保留与 D 相交的三角形的全部顶点。
   任一 G ∈ D 落在某个三角形内，三顶点距 G ≤ h ≤ 1000 m 且把 G 围在凸包内，因此不论定向方向如何，
   至少一个顶点落在该源的覆盖半平面内 → 一定能测到。某频道在**全部**格点均无信号 ⇒ 该频道无源。
   方案四用 h=950 m、偏移 (475.0, 411.4)、旋转 30°，共 27 点，巡回 25.1 km。
2. **有限兜底**：某源已确认存在但定位失败时，沿首条示向线把 0–1500 m × 宽 60 m 的条带切成 75×3 个 20 m 方格逐格清除，最多 225 次，必然清到。
3. **保守几何**：误差界取 1.005°（含两位小数舍入）；圆用外切 64 边形近似；区域半径 ≤19.5 m 才算"保证清除"。
4. **退出**：清满 16 个，或其余频道在全部格点均无信号。

策略层（可调）：

| 参数 | 值 | 含义 |
|---|---|---|
| x | 530 m | 顺路清除的绕行阈值：d(当前,源)+d(源,下一覆盖点)−d(当前,下一覆盖点) ≤ x 才顺路去清 |
| r_ok | 130 m | "可确认"阈值：源的可能区域半径 ≤ r_ok 才考虑去清 |
| 顺带补测夹角 | 12° | 在覆盖点上对已发现未清源补测一次的最小交会夹角（且该点到区域各顶点 ≤1500 m） |
| 局部补测距离上限 | 540 m | 补测点到区域中心的距离取 max(区域半径+15, min(540, 当前距离)) |
| 局部补测与长轴夹角 | ≥40° | 补测方向与区域长轴的夹角下限 |
| 局部补测次数上限 | 2 | 超过就转入逐格清除 / 兜底 |
| 直接逐格清除的格数上限 | 6 | 区域能被 ≤6 个 20 m 清除圆盖住就逐个试清（清除失败仅 3 s） |
| 最终清除顺序 | ALNS | 覆盖完成后对剩余源排序（移除 + 最小插入 + 2-opt，200 次迭代） |

调度：按固定巡回顺序（最近邻 + 2-opt）访问覆盖点 → 每点扫完所有未确认频道 → 顺带补测 → 用 x / r_ok 判断是否顺路清除 → 覆盖完成后集中清除。

### 结构性观察

1. **覆盖巡回是固定成本**：27 点巡回 25.1 km = 5022 s，占总时间约一半，且几乎与 N 无关。总时间对 N 不敏感（8520–8693 s），所以"每源时间"几乎就是"固定成本 ÷ N"。
2. **检测几乎都在证伪**：268 次扫描里 264 次返回 `no_signal`。定向源的 `no_signal` 不能用来推断位置（可能只是背面），所以这些检测只为覆盖证书服务。
3. **空频道昂贵**：最终为空的频道吃掉 13% 的时间；N=10 时高达 1606 s。空频道数 = 20 − N，每个都必须在全部 27 个点上测一遍。
4. **清除相关的移动是清除动作本身的 24 倍**（2084 s vs 86 s）。
5. **局部补测已经退化**：贝叶斯优化把补测上限压到 2 次、逐格清除上限提到 6 格后，局部补测只剩 9 s/局，几乎全靠"到附近后直接用 20 m 清除圆逐格试清"。

## 4. 已验证的三项改进

复现：`python code/experiments/方案五_候选ABC.py`

### A. 更短的合格覆盖网

在"边长 h ≤ 1000 m 三角格 + 保留与 D 相交三角形的全部顶点"这一**有解析证书**的族内，对 h ∈ [780,1000]、
8×8 偏移、6 个旋转穷举，取巡回最短者：**h = 900 m、偏移 (0, 487.0) m、旋转 10°，27 点，巡回 23 887 m**（方案四为 25 111 m）。
证书与方案四同构（h ≤ 1000），另用"位置 × 朝向"稠密复验（360 方向 × 62 半径 × 72 朝向）：**漏测 0**。

### B. 联合重规划（取代固定巡回 + x 阈值）

每一步把两类节点放在一起重排路线：still-pending 的覆盖点，和区域半径 ≤ r_ok 的已发现源；
用最近邻 + 2-opt 从当前位置排一条开放路径，执行排在最前的节点，然后重排。取消 x 阈值。

```
while 未清满 16:
    nodes = {还有未确认频道的覆盖点} ∪ {区域半径 ≤ r_ok 的已发现源}
    seq = 最近邻+2opt(nodes, 起点 = 当前位置)
    执行 seq[0]（扫描该覆盖点 / 清除该源）
```

注意：这与之前否掉的"两步前瞻 beam"不同——beam 只看两步、且用粗代价估计，把本已接近最优的巡回打乱；
联合重排每次都重建完整路线，保持了全局巡回质量。

### C. 计数提前停

题目保证总数 ≤ 16 且每频道至多一个源。因此一旦"已清除 + 已发现"达到 16，其余频道必为空，
可以立刻停止覆盖，转入集中清除。**这是与覆盖证书并列的第二条判空依据，必须写进保证链。**
只在 N=16 时触发，但那时收益最大。

## 6. 待研究方向（按预期收益排序）

**a. 更少点 / 更短巡回的方向覆盖证书。** 现在 27 点是"三角格 + 保留相交三角形顶点"的产物。按面积估算，
覆盖 D 加一圈外环理论上约需 21 点（π(1800+h/√3)² ÷ (√3h²/2)，h=1000 时约 20.5）。
需要：非格网的构造 + 可证明或可严格数值验证的"凸包条件"。注意抽样式集合覆盖已被证明不可靠——
我们试过位置 × 朝向抽样的集合覆盖（29 点、21.7 km），稠密复验漏测 641 组。
预期收益：巡回每少 1 km ≈ 200 s ≈ 每源 15 s（N=13）。

**b. 覆盖与清除的真正联合优化。** B 只是"每步重排最近邻"。可考虑：带利润的旅行商（清除是必访但时间可选）、
或把覆盖点访问顺序与清除插入一起做 ALNS / 大邻域搜索，目标是总虚拟时间而非路程。
预期收益：清除绕路 115 s/源里的一部分。

**c. 连续覆盖路径规划。** 现在"测点"必须是格点，但机器狗可以在任意位置停下测量。
把问题看成"沿一条路径选停靠点，使每个频道的停靠点集合满足凸包条件"，可能得到比格网更短的路径。
这是 coverage path planning + 方向可见性的结合，没查到现成结论。

**d. 定向源的方向推断。** 现在完全不用 `no_signal` 推断定向方向（为了不误判）。
若能在**保证层之外**用它加速定位（例如缩小补测候选方向），可能减少补测与兜底；
前提是任何推断都不能影响"判空"的证据链。

**e. 计数提前停的推广。** C 只在满 16 时触发。能否在"已发现 k 个 + 剩余频道的覆盖进度"之间做期望优化，
提前放弃部分覆盖点？注意：放弃覆盖点就失去该频道的判空依据，必须有替代证据（例如计数），否则不能用。

**f. 局部清除的最优停止。** 当前规则是"能被 ≤6 个清除圆盖住就逐格清，否则补测，最多 2 次"。
这是一个带随机性的最优停止问题（补测 5 s + 走路 vs 清除失败 3 s），可以解析建模。

**g. 频道扫描顺序。** 每点按"当前频道优先 + 编号"排序，切换成本 281 s/局；蛇形顺序最多再省约 27 s，边际。

## 8. 硬约束（不可为了提速而放弃）

1. 必须保证全部清除：覆盖证书（或等价的判空依据）+ 有限兜底，二者都必须真实存在于代码里。
2. 策略不得访问仿真真值（源坐标、数量、半径、类型、朝向、隐藏清除状态）。
3. 保守几何参数不得放松：1.005° 误差界、999 m 可探测余量、19.5 m 保证清除半径、28 m 清除方格（< 20√2）。
4. `no_signal` 对定向源不构成位置排除；`near` 必须单独处理；同点重复测量不提供新信息。
5. 官方接口：单个未决动作、幂等重试、同时检查 HTTP 状态与 `accepted`、用 `remaining_real_duration_s` 管理现实时间。
6. 一切改动都要重跑压力测试（≥120 局，含 5 种误差模型、半径下限、边界朝外），必须 100% 全清。
