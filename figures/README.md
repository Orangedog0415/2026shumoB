# 论文插图

32 张图，出图脚本在 `code/figures/`，每张图一个脚本，文件名与图名一一对应。
每个脚本都可以单独运行，重跑后覆盖同名的 `.pdf` 与 `.png`：

```powershell
cd <仓库根目录>
python code\figures\图11_覆盖网对比.py
```

- **`.pdf` 是矢量版**，插进 LaTeX / Word 用这个；`.png`（200 dpi）用于预览和贴进聊天。
- 统一样式在 `code/figures/_绘图样式.py`：三个分类色（蓝＝主对象、橙＝路线/对比、红＝超限与警示），
  其余走中性灰；中文字体优先 Noto Sans CJK / 微软雅黑 / 黑体，Linux 下退回文泉驿。
- 依赖：matplotlib；图 3/9/11/12/21 另需 numpy、scipy。

## 数据来源

| 文件 | 作用 |
|---|---|
| `code/figures/_绘图样式.py` | 配色、字体、坐标轴、流程图图元 |
| `code/figures/_问题二数据.py` | 问题二的外包络 P、安全候选域、评分场（图 5~8 共用） |
| `code/figures/_绘图数据采集.py` | 跑一遍四个版本采集逐局时间、时间分解、单局轨迹、压力测试逐局结果，写到 `code/experiments/results/绘图数据.json`（图 15~19、22 读它） |
| `code/experiments/results/图21_参数扫描.json` | 图 21(a) 的 x × r_ok 扫描缓存，删掉会自动重算 |
| `code/experiments/方案七_敏感性分析.py` | 四块敏感性扫描（策略参数 / 时间常数 / 源分布 / 保证假设），写到 `results/敏感性分析.json`（图 28~31 读它），支持断点续跑 |
| `code/figures/_敏感性数据.py` | 读上面的 JSON，供图 28~31 使用 |

**图 15~19、22 依赖 `绘图数据.json`**，如果没有这个文件，先运行：

```powershell
python code\figures\_绘图数据采集.py
```
